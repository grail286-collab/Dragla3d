# Логово Дракона 3D

Пошаговая 3D настольная игра для мобильного (портретный режим): 2–4 искателя золота
проникают в подземелье 24×24 с разных сторон и соревнуются, кто вынесет больше золота
из логова спящего дракона.

**Меню партии**: режим «Против ИИ» (вы + соперники-ИИ с именами и аватарками по полу:
Борин, Торин, Лориэль, Вельза…) или «На одном устройстве» (хот-сит на 2–4 человека).
Для каждого человека — выбор аватарки из 8 эльфийских портретов и имя героя.
Аватарки видны в HUD, над 3D-фишками и в итогах.

**Броски**: настоящие 3D-кубики с цифрами на гранях — тетраэдр d4 (движение) и икосаэдр
d20 (монстры, ловушки, дракон). Бросок — касанием самого кубика; после результата окно
закрывается само.

**Герои**: вместо фишек — 3D-модели искателей с факелами, сопоставленные с аватарками.
Пол выложен 9 случайными каменными тайлами, стены — тёмно-серая неровная кладка.

## Цель

Дойти до логова в центре, награбить золота и **живым выбраться к любому краю подземелья**.
Покинуть подземелье можно **только побывав в логове** — выход заперт для «пустых» искателей.
Побеждает выбравшийся с наибольшим золотом. Погибшие теряют всё.

## Правила

- **Ход**: бросок **d4** (всплывающее окно) — столько шагов можно сделать. Ходить можно
  по одной клетке за раз, необязательно тратить все шаги («Завершить ход»).
- **Туман войны**: поле закрыто; игра подсвечивает клетки, куда можно шагнуть, —
  коснитесь подсвеченной клетки, и под фишкой откроется тайл со стенами.
- **События на клетках** (генерируются случайно каждую партию):
  - 💰 золото и полезные предметы (Сапоги ветра +1 к d4, Амулет тени +2 у дракона) и артефакты
    (Клинок истребителя +4 против монстров, Плащ ночи +4 против ловушек,
    Кольцо невидимости — спасает от дракона один раз, Драконий глаз +50% золота в логове);
  - 🕸️ ловушки (дротики, яма с кольями, зыбучий песок) — проверка **d20** против сложности;
  - ⚔️ монстры (гремлин, гигантская крыса, скелет-страж, вампир) — бой броском **d20**:
    бросок выше сложности — победа и награда;
- **Жизни**: у каждого искателя **3 жизни ❤️**. Каждый неудачный бросок проверки монстра
  или ловушки отнимает одну жизнь (и часть золота). Жизни кончились — искатель погибает.
- **Логово дракона**: каждая кража — проверка d20. Успех приносит золото, но вероятность
  пробуждения растёт **+10%** за попытку. Проснувшийся дракон испепеляет воришку.
  В любой момент можно уйти — тогда нужно дойти до края подземелья.

## Управление

- Тап по подсвеченной клетке — шаг; тап по кубику — бросок; кнопки окон — выбор.
- **Обзор карты**: перетаскивание — панорама, щипок / колесо мыши — приближение.
  Двойной тап по портрету искателя вверху — вернуть камеру к нему.
- Esc / кнопка ⏸ — пауза, 🔊 — звук. Рекорд добычи хранится локально (localStorage).

## Запуск

```bash
npm ci
npm run build    # dist/
npm run verify   # playwright smoke-check: title → d4 → движение → события → ИИ → пауза
```

## Технически

- Three.js: инстансированные тайлы/стены/блоки тумана (~576 клеток в 3 draw call),
  плавные tween-перемещения фишек, камера всегда «за спиной» активного искателя,
  процедурный дракон с анимацией сна/пробуждения, частицы (золото, пыль, огонь).
- Идеальный лабиринт 24×24 (recursive backtracker) с вырезанным логовом 2×2 в центре;
  события раздаются seeded PRNG (mulberry32), чем ближе к центру — тем богаче тайники.
- Web Audio: синтезированные SFX (шаги, кубики, золото, бой, рёв дракона), без файлов.
- Чистая логика (model.ts) отделена от рендера (scene3d.ts), UI (ui.ts) и контроллера (game.ts).
